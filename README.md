# Pokédex Collection

Prototipo MVP de portal web (portal **Collection**) con los 151 Pokémon de la primera generación, hecho con ayuda de IA para el RETO "Una versión MVP de portal WEB creado con IA" (TC2007B, Tec de Monterrey).

Incluye modo PokéTec y funciones de accesibilidad: tamaño de texto, fuente legible, alto contraste, pantalla a color, regla de lectura, reducir animaciones, modos para daltonismo y lectura en voz alta.

Proyecto académico sin fines de lucro. Pokémon y sus nombres son marcas de Nintendo, Creatures y Game Freak. Datos e imágenes: [PokéAPI](https://pokeapi.co).
